## Quy ước

- **BR-xx**: yêu cầu nghiệp vụ. **NFR-xx**: yêu cầu phi chức năng.
- **Độ ưu tiên** theo MoSCoW: **M** (Must), **S** (Should), **C** (Could), **W** (Won't, chưa làm ở phiên bản này).
- **Milestone** M1–M7 theo kế hoạch đã duyệt:

| Milestone | Nội dung |
|---|---|
| M1 | Nền tảng |
| M2 | Thị trường và vĩ mô |
| M3 | Tin tức và AI |
| M4 | Bản đồ |
| M5 | Trending, lịch sự kiện, prediction markets |
| M6 | Môi trường, sức khỏe, Góc Việt Nam |
| M7 | Hoàn thiện |
| M8 | Trang Vĩ mô thế giới (BR-21) |
| M9 | Trang Việt Nam (BR-22) |
| M10 | Trang Công nghệ (BR-23) |
